# 🔥 Charizard AR

An Augmented Reality (AR) project developed using **Unity**, featuring an interactive Charizard experience in the real world.

## ✨ Features

- 📷 Image Tracking – Detects a target image using the device camera.
- 🐉 AR Character – Displays Charizard in an augmented reality environment.
- 🎮 Interactive Experience – Allows users to interact with the AR character.
- 📱 Android Support – Designed to run on Android devices.

## 🛠️ Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **AR Framework:** AR Foundation
- **IDE:** Visual Studio

## 🚀 Getting Started

### Requirements
- Unity Hub
- Unity Editor
- Android device
- Android Build Support
- AR-compatible Android device

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/krishnaprasanth7102/CharizardAR.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Select the cloned project folder.
5. Open the project using the compatible Unity Editor version.
6. Connect your Android device.
7. Build and run the project.

## 📸 How to Use

1. Install and launch the application.
2. Point your camera towards the target image.
3. Wait for the image to be detected.
4. Watch Charizard appear in the AR environment.
5. Interact with the virtual character.
